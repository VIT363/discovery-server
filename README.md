Задача:
Создайте проект Eureka Server — реестр, в котором микросервисы регистрируются и 
находят друг друга по имени.
Зарегистрируйте микросервис конвертации файлов (из практики 1) как Eureka-клиента.

Важное требование к структуре:
В обучающих материалах микросервисы часто создают как модули одного проекта. 
Ваша задача — наоборот: создать каждый микросервис отдельным проектом и хранить 
каждый в своём репозитории на GitHub. Так система ближе к реальной микросервисной архитектуре,
где сервисы разрабатываются и деплоятся независимо.
